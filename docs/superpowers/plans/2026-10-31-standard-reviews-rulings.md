# Standard reviews: the rulings made while carrying out the plan

The decisions taken while executing [the plan](2026-10-31-standard-reviews.md) for [the spec](../specs/2026-10-30-standard-reviews-design.md), where the plan, the spec and the reviews left a choice. Each reads: what was decided — why — what it costs if wrong. Copied from the run's ledger on 2026-11-02.

- **R1.** Restore runs check(text, exists=…) without a parent: three parts and test existence, no dropped-items check — the restored text passed the check when first recorded and a restore deliberately removes what a bad edit added; its note is the reason — cost if wrong: a restore could drop a reference without a Dropped line (maintainers only).

- **R5.** In the edit check, a parent reference also counts as kept when its normalised text is contained in a new reference's normalised text (besides similarity ≥ 0.6) — an edit that adds a theorem number to a reference is the improvement the design wants, and the ratio rule refuses it — cost if wrong: a reference rewritten to contain the old one plus a contradiction passes the check (the check never judged content anyway).
